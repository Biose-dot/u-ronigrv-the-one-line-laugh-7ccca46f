Entry for the [make.fun](https://make.fun) bounty
[The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f).

One funny line — a single sentence of at most 200 characters, any topic. The house judge reads the lines two at a time and keeps the bigger laugh.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> My smart speaker heard me say I was lonely, so now it keeps offering me a support line for my feelings.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
